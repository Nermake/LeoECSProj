# LeoECSProj

 Unity version: 2022.3.44f1

## Info

A `Demo Project` in which only a part of a full-fledged game is implemented. The main point: to show the way to use the `LeoEcs` & `Zenject` frameworks.

---

## What can be seen in the demo

There will be only one scene called Demo inside the scene folder. When it starts, there will be a console on the stage where you can enter some commands.

**Commands:**
- Actor Factory:
  - `af_ch` - creates a hero (commands that require a hero will not work until you create a hero using this command)
  - `af_add_hp` - increases the current hp
  - `af_add_mana` - increases the current mana
  - `af_reduce_hp` - reduces the current hp
  - `af_reduce_mana` - reduces the current mana
  - `af_change_sr` - changes the current secondary resource(mana/energy/rage)
- Others:
  - `create_ability` - creates 3 abilities (instant Heal, periodic heal, heal that must be cast)
  - `lvlup_add` - increases the level or amount of experience depending on the set parameters
  - `race_change` - changes the race of the hero
  - `gold_change` - increases or decreases the amount of gold depending on the input parameters
